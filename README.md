# Support Engineering Blog

The Support Engineering Blog is a static Astro site focused on technical documentation,
Microsoft 365 administration, and support engineering resources.

## Technology

- Astro
- MDX
- Pagefind
- Astro Sitemap
- Astro RSS
- TypeScript
- CSS

## Project Structure

```text
src/
├── assets/
│   └── css/
├── components/
├── config/
├── content/
│   └── articles/
├── data/
├── layouts/
├── lib/
├── pages/
├── scripts/
└── utils/
```

## Content

Articles are stored in:

```text
src/content/articles/
```

Both Markdown and MDX files are supported.

Article frontmatter is validated through:

```text
src/content.config.ts
```

Published articles are automatically excluded from listings when:

```yaml
draft: true
```

## Commands

Run from the project root:

```bash
npm install
npm run dev
npm run build
npm run preview
```

`npm run build` creates the production site in `dist/`.

## Notes

- Search is powered by Pagefind.
- The sitemap is generated by `@astrojs/sitemap`.
- The RSS feed is generated from the published article collection.
- Google Analytics is loaded only after analytics consent is granted.
