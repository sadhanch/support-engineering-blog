# Scheduled Publishing Test

This is a temporary article used to validate the Support Engineering Blog's scheduled publishing workflow.

## Why this article exists

The Support Engineering Blog uses Astro to generate a static site and Cloudflare Pages to deploy it. Scheduled publishing adds an editorial timing layer so an approved article can exist in the Git repository before its intended publication time without appearing on the public site too early.

For this test, the article contains a future `publishAt` timestamp.

## Expected behavior

The article currently has:

```yaml
draft: false
publishAt: "2026-12-31T09:00:00+05:30"
```

That combination should mean:

- the article is approved for publication;
- the article is not yet eligible for the generated site;
- the article should be excluded from article discovery and generated routes until `publishAt` is reached.

## Publication test

To test the second half of the workflow, temporarily change `publishAt` to a timestamp in the past, such as:

```yaml
publishAt: "2026-08-23T09:00:00+05:30"
```

Then run the Astro build again.

The article should become part of the generated site.

## Test cleanup

This article is temporary and should be deleted after the scheduled-publishing tests are complete.

## Expected Result

The test validates the intended publication states:

| State | Expected result |
| --- | --- |
| `draft: true` | Not published |
| `draft: false` + future `publishAt` | Not published |
| `draft: false` + past `publishAt` | Published |
| `draft: false` + no `publishAt` | Existing articles continue to publish normally |
