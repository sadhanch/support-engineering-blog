## Getting Started with Microsoft Graph

Microsoft Graph provides a unified API for accessing Microsoft 365 services.

## Why Microsoft Graph?

Administrators can automate repetitive tasks while integrating with Microsoft 365 workloads.

## Connect using PowerShell

```powershell
Connect-MgGraph

Get-MgOrganization

Get-MgUser -Top 10
```

## Common scenarios

- User management
- License reporting
- Group administration
- Device inventory

## Conclusion

Microsoft Graph is becoming an essential skill for modern Microsoft 365 administrators.
